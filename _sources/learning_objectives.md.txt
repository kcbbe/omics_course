# Learning objectives

## General Omics and Sequencing Technologies

In the introductory part of this course, participants will:

- Identify major classes of omics data, including genomics, transcriptomics, epigenomics, proteomics, and metabolomics.
    
- Understand the biological questions each omics layer addresses and how these layers relate to one another within the flow of information from DNA to RNA to protein to cellular phenotype.
    
- Distinguish between common sequencing-based omics approaches used for expression and regulatory profiling, such as bulk RNA-seq, single-cell RNA-seq, ATAC-seq, ChIP-seq, and DNA methylation profiling.
    
- Recognize the type of information each sequencing assay provides (e.g. gene expression, chromatin accessibility, transcription factor binding, histone modifications, DNA methylation).
    
- Understand, at a conceptual level, how different sequencing-based assays complement each other in describing gene regulation and cellular state.
    
- Appreciate why RNA-seq is widely used as a general-purpose assay for transcriptome profiling and how it fits within the broader landscape of omics technologies.
   
## RNA-seq analysis

After this general overview, the course focuses in detail on the experimental design, data generation, and analysis of bulk RNA-seq experiments. Upon completion, participants should be able to:

- Describe the major stages of an RNA-seq experiment, from experimental design and sample preparation to sequencing and data generation.
    
- Identify key considerations in experimental setup, including biological replicates, controls, library preparation strategies (e.g. poly(A) selection versus rRNA depletion), and sequencing depth.
    
- Understand the structure and content of typical RNA-seq data files (e.g. FASTQ files, count matrices, sample metadata).
    
- Outline a standard RNA-seq analysis pipeline, including quality control, normalization, differential expression analysis, and downstream functional interpretation.
    
- Recognize the purpose and interpretation of common visualizations used in RNA-seq analysis (e.g. PCA plots, volcano plots, MA plots, heatmaps, boxplots, pathway and gene set enrichment plots).
    
- Follow an annotated R Markdown workflow that implements an end-to-end RNA-seq analysis using established software packages.
    
- Reproduce example analyses, modify parameters, and assess how these changes affect results and interpretation.
    
- Interpret differential expression and pathway-level results in the context of the underlying biological question.
    
The course focuses on practical understanding and interpretation rather than on the mathematical details of statistical modeling, enabling participants to critically evaluate RNA-seq results and communicate findings effectively.

# Who should attend?

This course is intended for graduate students, postdoctoral researchers, and other life scientists who generate or plan to generate RNA-seq data and want to better understand how these experiments are designed, analyzed, and interpreted.  The course is also relevant for educators who teach genomics or transcriptomics and are looking for structured, practical content that can be adapted to design or supplement their own courses.
Participants should have a background in molecular or cellular biology who may have limited formal training in bioinformatics but wish to become more informed and critical users of transcriptomics data.

# Program
## Day 1 : Morning

### Lecture: Introduction into general ~omics technologies
This lecture provides an overview of the major omics domains, including genomics, transcriptomics, epigenomics, proteomics, metabolomics, and microbiomics. The relationships between these layers and their roles in describing cellular state and function are discussed. Emphasis is placed on the types of biological questions that each technology can address.

### Guest lecture
A guest speaker presents an application of omics technologies in a real research context. The lecture illustrates how experimental design, data generation, and interpretation are combined in practice. 

### Lecture: Introduction into sequence-based ~omics technologies
This lecture focuses on sequencing-based assays such as RNA-seq, ATAC-seq, ChIP-seq, DNA methylation profiling, and single-cell RNA-seq. The type of information generated by each assay and typical use cases are described. The conceptual similarities and differences between these approaches are highlighted.


## Lunch

## Day 1 : Afternoon

### Lecture: Design and data analysis for RNA-seq
This session covers the most important considerations in planning RNA-seq experiments, including replicates, controls, library preparation strategies, and sequencing depth. An overview of a standard RNA-seq analysis pipeline is presented, from raw data to differential expression results. Common pitfalls and sources of technical variation are discussed.

### Guest lecture
A second guest lecture with an example RNA-seq study, emphasizing practical aspects of experimental setup and downstream analysis. The emphasis is on how results are validated and integrated with other data types. This lecture provides a complementary real-world perspective on the theoretical lectures.

### Lecture: Biological interpretation of RNA-seq data
This lecture introduces approaches for interpreting gene-level results in a biological context. Topics include visualization, pathway analysis, gene set enrichment, and comparison across conditions. The strengths and limitations of different interpretation strategies are discussed.

### Lecture: Gentle introduction into programming languages R and Python
Participants are introduced to the basic concepts of scripting and data analysis in R and Python. The focus is on understanding code structure, reading data, and running simple analyses. No prior programming experience is assumed. This lecture can be regarded as a primer for the more hands-on sessions on day 2.

## Diner


## Day 2 : Morning

### Lecture: The use of public (web-based) analysis tools
This lecture introduces commonly used web-based platforms for gene expression and pathway analysis. Strengths and limitations of these tools are discussed. Emphasis is placed on appropriate use and interpretation of results.

### Hands-on: Use of public tools for gene set analysis
Participants work with selected public tools to perform gene set or pathway enrichment analysis. Example gene lists are provided, and results are explored interactively. The goal is to gain practical experience and confidence with these resources.

### Lecture: Gentle introduction into R and DESeq2
This lecture introduces the DESeq2 framework for differential expression analysis in R. The main analysis steps and required inputs are explained conceptually. This session prepares participants for the hands-on RNA-seq analysis later in the course.

## Lunch

## Day 2 : Afternoon

### Lecture: Analysis of BCOR data sets with R
This lecture walks through the structure of the BCOR RNA-seq data set and the overall analysis strategy. Key steps in the R Markdown workflow are explained. The focus is on understanding how the code implements the concepts introduced earlier.

### Hands-on: Analysis of BCOR data set (accounts on a server will be provided)
Participants run the analysis workflow on the BCOR data set using provided server accounts. They reproduce selected results and explore the effects of changing parameters. Instructors are available for guidance and troubleshooting.

### Lecture: The use of ChatGPT and similar tools for biological analysis
This lecture discusses how large language models can be used to support data analysis, coding, and interpretation. Examples of appropriate and inappropriate use are presented. Limitations, reproducibility, and good practice are emphasized.
