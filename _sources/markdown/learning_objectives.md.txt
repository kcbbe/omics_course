# Course information "Bioinformatics for Epigenomics"

This course is intended to make participants familiar with the major bioinformatic concepts and practical steps involved in the analysis and interpretation of epigenomic data, with a focus on transcriptomic (RNA-seq) analysis. This focus is chosen because a lot of epigenetic modifications are evaluated with RNA-seq and a lot of statistical principles that are valid for all epigenomics data can be best demonstrated on gene count data.

<hr>

# Learning objectives

## Epigenomics

* Learn about the biological processes that govern the most important epigenomic mechanisms.
* Distinguish between common sequencing-based omics approaches used for expression and regulatory profiling, such as bulk RNA-seq, ATAC-seq, ChIP-seq, and DNA methylation profiling.
* Recognize the type of information each sequencing assay provides (e.g. gene expression, chromatin accessibility, transcription factor binding, histone modifications, DNA methylation).
* Understand the data formats that are produced by each sequencing technique and how these data can be processed and interconverted.
* Understand and learn how these data can be visualized using publicly available web tools.

## RNA-seq

* Understand the general principles behind RNA-seq, including experimental setup and the structure and content of typical RNA-seq data files (e.g. FASTQ files, count matrices, sample metadata).
* Outline a standard RNA-seq analysis pipeline, including quality control, normalization, differential expression analysis, and downstream functional interpretation.
* Use publicly available web-based tools to perform gene set analysis and biological interpretation, including gene set enrichment tools and tools based on large language models.

## Bioinformatics

* Follow an annotated R Markdown workflow for visualization and analysis of ChIP-seq and methylome sequencing data.
* Follow an annotated R Markdown workflow that implements an end-to-end RNA-seq analysis using standard software libraries.
* Recognize the purpose and interpretation of common visualizations used in epigenomics and transcriptomics data analysis (e.g. PCA plots, volcano plots, heatmaps, Venn diagrams, boxplots, pathway and gene set enrichment plots).
* Reproduce example analyses, modify parameters, and assess how these changes affect results and interpretation.
* Interpret differential expression and pathway-level results in the context of the underlying biological question.

# Who should attend?

This course is primarily intended for teachers in HBO and universities environments. The focus during the course will be on working with example data files and exercises that can be translated into a curriculum for students. The course is also useful for graduate students, postdoctoral researchers, and other life scientists who generate or plan to generate sequence-based omics data and want to better understand how these experiments are designed, analyzed, and interpreted. Participants should have some background in molecular or cellular biology but may have limited prior knowledge of bioinformatics and programming.

# Program

Throughout the course we will make use of data and visualizations drawn from the following paper:
**BCOR and BCORL1 Mutations Drive Epigenetic Reprogramming and Oncogenic Signaling by Unlinking PRC1.1 from Target Genes**
DOI: 10.1158/2643-3230.BCD-21-0115 / PMID: 35015684

This paper describes studies on knockout of proteins (BCOR and BCORL1) involved in epigenetic modification of the genome. The study contains publicly available DNA methylation sequencing, ATAC-seq, ChIP-seq, and RNA-seq data.

The downloaded and processed data from this paper, as well as R scripts for the analysis, are available for use in the course. Participants should bring their own laptop to work with publicly available web tools. Analysis with the provided R scripts will be done on a server, for which access will be provided.

## Day 1 : Morning 9.30 - 12.30

### Lecture: Introduction to epigenomics (30 min)

This lecture introduces the major epigenetic mechanisms, including DNA methylation, histone modifications, and chromatin accessibility. The relationship between epigenetic regulation and gene expression is discussed.

### Lecture: Methylome sequencing (30 min)

An overview of bisulfite sequencing and related methods for measuring DNA methylation. The type of data produced, typical analysis steps, and common applications are explained.

### Hands-on: Working with methylome sequencing data (60 min)

Participants explore example methylation data using prepared files and web-based analysis and visualization tools. The focus is on understanding data structure and basic interpretation.

### Guest lecture (45 min)

A guest speaker presents a case example of epigenomics in a research setting, illustrating experimental design, analysis, and biological interpretation.

## Day 1 : Afternoon 13.30 - 17.00

### Lecture: Introduction to ATAC-seq and ChIP-seq (30 min)

This lecture explains the principles behind chromatin accessibility and protein–DNA binding assays. Typical experimental designs and resulting data types are discussed.

### Hands-on: Working with ChIP-seq and ATAC-seq data (60 min)

Participants work with example datasets to visualize peaks and genomic coverage. Emphasis is placed on understanding what the signals represent biologically.

### Lecture: Introduction to RNA-seq (30 min)

This lecture introduces RNA-seq as a method for transcriptome profiling. Experimental setup, sequencing strategies, and basic analysis concepts are covered.

### Lecture: The use of public (web-based) analysis tools (30 min)

An overview of commonly used web-based platforms for gene expression and pathway analysis. Strengths and limitations of these tools are discussed.

### Hands-on: Working with public tools for gene set analysis (45 min)

Participants perform gene set or pathway enrichment analyses using example gene lists. Results are explored and interpreted.

## Day 2 : Morning 9.30 - 12.30

### Lecture: Gentle introduction to R (30 min)

Basic concepts of R scripting, objects, and data structures are introduced. No prior programming experience is assumed.

### Hands-on: Creating visuals with R, dplyr and ggplot2 (60 min)

Participants work with prepared genome coverage datasets (bedGraph files) and create plots showing signal across genomic regions. This serves as an introduction to tidyverse-style data handling and visualization of sequencing data.

### Lecture: Statistical analysis of RNA-seq data (30 min)

This lecture introduces differential expression analysis using DESeq2. Topics include quality control, normalization, and common visualizations such as PCA, volcano plots, heatmaps, and boxplots.

### Hands-on: Working with R and DESeq2 (60 min)

Participants learn how to specify an experimental design, perform differential expression analysis, and visualize results.

### Guest lecture (45 min)

Guest lecture presenting an example RNA-seq study, emphasizing practical aspects of experimental setup and downstream analysis.

## Day 2 : Afternoon 13.30 - 17.00

### Lecture: Introduction to biological interpretation of gene sets (45 min)

This lecture covers pathway analysis and comparison across conditions. Examples are drawn from RNA-seq as well as epigenomics-derived gene sets.

### Hands-on: Working on gene sets (60 min)

Participants run the analysis workflow on the BCOR dataset using provided server accounts and an example R template file. They reproduce selected results and explore parameter changes.

### Lecture: The use of ChatGPT and similar tools for biological analysis (30 min)

This lecture discusses how large language models can support data analysis, coding, and interpretation, including limitations and good practice.

### Hands-on: Working with AI tools (30 min)

Participants use web-based AI tools to generate biological interpretations based on supplied gene sets.
