# Standard approach for identifying regulated genes

A common way to identify regulated genes in RNA-seq data is to apply thresholds based on both **effect size** and **statistical significance**. Effect size is typically expressed as a **log₂ fold change (log₂FC)**, which quantifies how strongly a gene’s expression differs between two conditions. For example, a log₂FC of +1 corresponds to a two-fold increase in expression, while a log₂FC of −1 indicates a two-fold decrease.

Statistical significance is assessed using a **p-value**, which tests the null hypothesis that a gene shows no true difference in expression between the conditions being compared. In DESeq2, this p-value is derived from a Wald test within a negative binomial model that accounts for differences in sequencing depth and biological variability. However, because thousands of genes are tested simultaneously, many small p-values are expected by chance alone. To correct for this, DESeq2 applies the **Benjamini–Hochberg procedure** to control the false discovery rate (FDR), resulting in an **adjusted p-value** (often denoted _padj_). The adjusted p-value reflects the probability of observing a false positive after accounting for multiple testing.

Using these metrics, a typical strategy is to define regulated genes as those showing both a sufficiently large fold change (e.g., |log₂FC| ≥ 1, corresponding to at least a two-fold difference) and strong statistical support (e.g., _padj_ < 0.05). This combined threshold ensures that selected genes exhibit biologically meaningful expression changes with high statistical confidence.

The identification of regulated genes in this analysis is based on the application of a statistical model as implemented in the R-package **DESeq2**, which estimates dispersion, fits count-based models, and performs hypothesis testing to assess differential expression. A detailed discussion of the underlying statistical framework and model assumptions is beyond the scope of this course. Numerous high-quality tutorials, reviews, and video lectures are available that explain these concepts in depth and provide theoretical background for users who wish to explore them further. In this course, the focus is on interpretation and downstream analysis of the results, while an example of how the DESeq2 model is specified and applied in practice can be found directly in the accompanying HTML report generated from the R Markdown file.
