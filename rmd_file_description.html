Example file

This course is accompanied by an R Markdown (Rmd) document that serves as a fully documented, executable record of the RNA-seq analysis workflow. The Rmd file contains the complete analysis code, interleaved with explanatory text that describes the rationale behind each step and commented code. The script spans the entire workflow, from reading in raw count data and performing normalization and quality control, through differential expression analysis, to higher-level biological interpretation using visualization and functional analysis methods. Readers are encouraged to actively engage with the material by reproducing the code examples, modifying parameters, and exploring how these choices influence the results and their interpretation. All figures shown in this course are direct outputs of the Rmd file and are copied from the corresponding HTML report, ensuring a transparent link between the code, the analysis, and the presented results.

The analysis report can be found here

The analysis code is written in R and relies on widely used packages such as DESeq2 for differential expression analysis, ggplot2 for data visualization, and the tidyverse for data manipulation and organization. While the implementation is provided in R, the overall analytical strategy is independent of the programming language, and a similar end-to-end workflow can be implemented in other environments, such as Python, using conceptually equivalent tools and libraries such as Pandas, matplotlib and PyDESeq2.
